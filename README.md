# Controle de Gastos

Sistema de controle de gastos residenciais desenvolvido como desafio técnico.

## Tecnologias

### Backend
- .NET 8
- C#
- Entity Framework Core
- SQLite

### Frontend
- React
- TypeScript
- Vite

## Funcionalidades

- Cadastro de pessoas
- Listagem de pessoas
- Exclusão de pessoas
- Cadastro de transações
- Listagem de transações
- Regra de negócio para menores de 18 anos
- Consulta de totais financeiros

## Como executar

### Backend

Entre na pasta:

cd backend

Execute:

dotnet run

O backend estará disponível em:

http://localhost:5252

### Frontend

Entre na pasta:

cd frontend

Instale as dependências:

npm install

Execute:

npm run dev

O frontend estará disponível em:

http://localhost:5173
